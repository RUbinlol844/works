# СИГНАЛ — сайт рекламного агентства

Одностраничный сайт рекламного агентства полного цикла. Чистый HTML/CSS/JS,
без сборки и зависимостей — открывается двойным кликом по `index.html`.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка и весь контент |
| `style.css` | Стили, адаптив, анимации |
| `script.js` | Меню, появление блоков, счётчики, FAQ, валидация формы |

## Что на странице

- Шапка с навигацией и мобильным меню
- Hero-блок с анимированным графиком кампании
- Бегущая строка и логотипы клиентов
- Услуги (6 направлений)
- Кейсы с результатами в цифрах
- Процесс работы (5 этапов)
- Форматы сотрудничества (проект / ретейнер / спринт)
- О нас со счётчиками
- Отзывы, FAQ-аккордеон
- Форма заявки с валидацией и контакты
- Подвал

## Как посмотреть локально

Просто откройте `index.html` в браузере.

Если нужен локальный сервер (например, для проверки на телефоне):

```bash
# Python 3
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Как выложить на GitHub Pages

1. Создайте репозиторий, например `signal-agency`.
2. Загрузите три файла: `index.html`, `style.css`, `script.js`
   (кнопка **Add file → Upload files** на странице репозитория).
3. **Settings → Pages** → *Deploy from a branch* → ветка `main` → папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ваш-логин.github.io/signal-agency/`.

Либо через git:

```bash
git init
git add .
git commit -m "Сайт рекламного агентства"
git branch -M main
git remote add origin https://github.com/ваш-логин/signal-agency.git
git push -u origin main
```

## Что стоит заменить перед публикацией

- Название агентства «СИГНАЛ» и логотип-заглушку (`.logo`)
- Телефон, e-mail, адрес и часы работы — в шапке, блоке контактов и подвале
- Кейсы, отзывы и цифры — сейчас это демонстрационные данные
- Форма пока работает в демо-режиме: данные никуда не уходят.
  Чтобы принимать заявки, подключите сервис (Formspree, Getform, Telegram-бот)
  в обработчике `form.addEventListener("submit", ...)` в `script.js`

## Цвета

Меняются в `:root` в начале `style.css`:

```css
--ink: #0b0b0c;      /* основной тёмный */
--paper: #f4f1ea;    /* светлый фон */
--accent: #d7ff3e;   /* кислотный лайм */
--warm: #ff4d2e;     /* акцентный оранжевый */
```

## Адаптивность

Контрольные точки: 1100px, 960px, 760px, 420px. Проверено на ширине
360–1440px. Есть поддержка `prefers-reduced-motion` для отключения анимаций.
